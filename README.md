# Frostwood

A first-person winter forest that runs in a single HTML file (Three.js from a CDN).

**Play:** https://canberkhayretdag.github.io/frostwood/

Day/night cycle with northern lights, blizzards, reindeer herds, ravens, snow hares, foxes, a campfire, a hunter's cabin, a climbable watchtower, cracking lake ice, footprints that fill with snow, and a photo mode.

## Controls
WASD walk · Mouse look · Shift run · Space jump · 1–9 viewpoints · T time speed · N day/night · B blizzard · P photo mode · M mute · H stats · Esc menu
